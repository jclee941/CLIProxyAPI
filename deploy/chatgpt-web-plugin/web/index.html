CLIProxyAPI 플러그인

ChatGPT Web

자격증명별 ChatGPT Web 한도와 Codex 사용량을 따로 보여줍니다. 조회만 하며 생성이나 토큰 갱신은 하지 않습니다.

gpt-web-chat, gpt-6-pro, gpt-web-image 호출은 웹 세션 한도를 쓰고, Codex 사용량은 API 한도라 따로 집계됩니다.

API 레퍼런스

이 플러그인이 제공하는 두 모델의 호출 방법입니다. $CLIPROXY는 이 프록시의 베이스 URL, $CLIPROXY_KEY는 발급받은 API 키입니다.

POST/v1/chat/completions웹 세션 한도 소비

요청

curl -X POST "$CLIPROXY/v1/chat/completions" \
  -H "Authorization: Bearer $CLIPROXY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-6-pro",
    "messages": [{ "role": "user", "content": "한 문장으로 자기소개 해줘" }]
  }'

지원 필드

필드설명
modelgpt-web-chat은 웹 기본(auto), gpt-6-pro는 ChatGPT GPT-6 Pro입니다. 둘 다 웹 세션으로 라우팅됩니다.
messages여러 턴을 보낼 수 있습니다. tool 역할과 이전 tool_calls도 이어붙여 대화 맥락으로 전달합니다.
tools웹 제품에는 함수 호출이 없어, 도구 계약을 프롬프트로 지시하고 응답에서 호출 블록을 파싱해 tool_calls로 복원합니다.
tool_choice도구 사용 강제 여부를 같은 프롬프트 지시에 반영합니다.

제약

  • 스트리밍 불가. stream: true는 image_streaming_unsupported로 거부합니다.
  • 텍스트 입출력만 지원합니다.
  • Codex API 한도가 아니라 브라우저 세션 한도를 소비합니다.
POST/v1/images/generations웹 image_gen 한도 소비

요청

curl -X POST "$CLIPROXY/v1/images/generations" \
  -H "Authorization: Bearer $CLIPROXY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-web-image",
    "prompt": "수채화풍 바닷가 등대",
    "size": "1024x1024",
    "output_format": "png"
  }'

지원 필드

필드타입설명
promptstring생성할 이미지 설명입니다.
sizestring해상도. 웹 대화 경로에는 전송 필드가 없어 프롬프트 문장으로 실어 보냅니다. 1024x1536(세로)·1536x1024(가로)·1024x1024 실측 확인.
qualitystring같은 방식으로 프롬프트에 실립니다. auto면 생략합니다.
output_formatstring응답에 붙는 형식 라벨입니다. 생략하면 png.
n · background—전달되지 않습니다. 한 번에 한 장만 생성됩니다.

오류

코드의미
content_policy_violation업스트림이 이미지 대신 거절로 답했습니다. 폴링을 기다리지 않고 즉시 돌려주며, 같은 프롬프트는 다른 자격증명으로도 재시도하지 않습니다.
web_image_not_ready폴링 예산 안에 이미지가 나오지 않았습니다. 짧은 창의 생성 제한에 걸렸을 때 나타납니다.
web_transport_failed업스트림 연결이 실패했습니다. 전송 전 실패는 자동으로 재시도합니다.

실패해도 HTTP 상태는 200으로 도착할 수 있습니다. 성공·실패는 상태코드가 아니라 본문의 error 객체 유무로 판단하세요.

GET/v0/management/plugins/chatgpt-web/accounts이 화면이 쓰는 조회

요청

curl "$CLIPROXY/v0/management/plugins/chatgpt-web/accounts" \
  -H "Authorization: Bearer $MANAGER_ADMIN_KEY"

자격증명별 한도만 돌려주는 조회 전용 경로입니다. 생성도, 토큰 갱신도 하지 않습니다.
