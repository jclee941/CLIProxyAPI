Gemini Web 계정 관리 화면을 준비하고 있습니다.

OpenAPI 연동 가이드

이 문서는 Gemini Omni Video API 연동을 위한 소비자용 요약 가이드입니다.
전체 명세는 https://cliproxy.jclee.me/openapi.json 에서 확인할 수 있습니다.

POST/v1beta/interactions영상 생성 및 연장

새 영상 생성 (Create)

새로운 영상을 생성합니다. 기본 비율은 세로(9:16)이며, response_format.aspect_ratio: "16:9"를 지정해 가로로 생성할 수 있습니다.

신규 대화는 영상 3회(생성과 연장 2회)를 끝낼 수 있는 계정에 라운드로빈으로 배정합니다. 5시간 또는 7일 사용량이 소진된 계정, 영상 생성 한도가 소진된 계정, 두 창 중 한 곳이라도 영상 3회분이 남지 않은 계정은 다시 가능해질 때까지 제외하며, 배정할 계정이 없으면 409 account_unavailable을 반환합니다.

curl -X POST "https://cliproxy.jclee.me/v1beta/interactions" \
  -H "Authorization: Bearer $YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-omni-1.1-flash",
    "input": "노을 지는 해변을 걷는 사람",
    "store": true
  }'

기존 영상 연장 (Extend)

완료된 영상의 ID와 generation_config.video_config.task = "extend"를 사용해 영상을 연장할 수 있습니다. 약 10초 영상의 3회 연장(최대 약 40초)이 관측되었으나, 이는 보장된 길이 한계나 연장 단위가 아닙니다.

연속 요청은 원래 계정이 처리할 수 있으면 같은 계정·같은 대화에서 이어집니다. 원래 계정이 막혀 있으면 다른 계정이 저장된 영상을 이어받아 생성하고, 새 ID는 그 계정에 속합니다. 다음 연장에는 항상 가장 최근에 받은 ID를 사용하세요.

curl -X POST "https://cliproxy.jclee.me/v1beta/interactions" \
  -H "Authorization: Bearer $YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-omni-1.1-flash",
    "input": "이전 장면에서 자연스럽게 이어지도록",
    "previous_interaction_id": "COMPLETED_INTERACTION_ID",
    "generation_config": {
      "video_config": {
        "task": "extend"
      }
    },
    "store": true
  }'

응답 처리

생성은 수 분이 걸릴 수 있습니다. HTTP 200 응답만으로 성공을 단정할 수 없으며, status: "completed" 상태와 steps[].content[].data에 비디오 데이터가 있어야 사용 가능합니다.

네트워크 오류 등 불확실한 POST 결과에 대해 자동으로 재시도하지 마세요. 반환받은 ID를 사용해 GET으로 상태를 조회해야 합니다.

GET/v1beta/interactions/{interaction_id}상태 및 결과 조회 (Retrieve)

요청

불확실한 생성 상태를 확인하거나 완료된 결과를 가져옵니다. 추가 생성을 유발하지 않습니다.

curl "https://cliproxy.jclee.me/v1beta/interactions/$INTERACTION_ID" \
  -H "Authorization: Bearer $YOUR_API_KEY"
