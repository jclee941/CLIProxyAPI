GWGemini Web

CLIProxyAPI 플러그인

Gemini Web 계정 관리 화면을 준비하고 있습니다.

요청 방법

OpenAI 호환 POST /v1/chat/completions과 Gemini 네이티브 POST /v1beta/models/{model}:generateContent를 모두 받습니다. 아래 예시의 $CLIPROXY는 이 프록시의 베이스 URL, $CLIPROXY_KEY는 발급받은 API 키입니다.

POST/v1beta/models/gemini-web-omni:generateContent호출당 영상 1건 소비

요청

curl -X POST "$CLIPROXY/v1beta/models/gemini-web-omni:generateContent" \
  -H "x-goog-api-key: $CLIPROXY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      { "role": "user", "parts": [{ "text": "노을 지는 해변을 걷는 사람" }] }
    ],
    "generationConfig": {
      "aspectRatio": "9:16",
      "negativePrompt": "자막, 워터마크"
    }
  }'

generationConfig

필드타입허용값설명
aspectRatiostring16:9 · 9:16 · 1:1화면비. 웹 영상 도구는 옵션을 전송 필드로 받지 않아 프롬프트에 문장으로 합쳐 보냅니다. 공식 UI의 화면비 선택과 동일하게 보장이 아닌 best-effort입니다.
negativePromptstring자유 문자열제외할 요소. 프롬프트에 합쳐집니다.
candidateCountnumber1한 번의 제출은 영상 하나만 만듭니다.

그 밖의 키(durationSeconds, resolution, personGeneration 등)는 전송 필드도 프롬프트 대응물도 없어 omni_unsupported_generation_option으로 거부합니다.

응답

{
  "modelVersion": "gemini-web-omni",
  "candidates": [{
    "index": 0,
    "finishReason": "STOP",
    "content": {
      "role": "model",
      "parts": [{ "inlineData": { "mimeType": "video/mp4", "data": "AAAAIGZ0eXB…" } }]
    }
  }]
}

업스트림 다운로드 URL이 세션 쿠키로만 열리기 때문에 링크 대신 base64 본문으로 돌려줍니다.

제약

  • contents는 정확히 한 턴, role은 user이거나 생략, 파트는 text만.
  • 스트리밍 불가. stream: true는 거부합니다.
  • 프롬프트는 합쳐진 옵션 문장을 포함해 8000자 이하, 본문은 5MiB 이하.
  • 영상이 준비될 때까지 최대 10분 폴링합니다.
POST/v1/chat/completionsOpenAI 호환 · gemini-web-omni

요청

curl -X POST "$CLIPROXY/v1/chat/completions" \
  -H "Authorization: Bearer $CLIPROXY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-web-omni",
    "messages": [{ "role": "user", "content": "노을 지는 해변을 걷는 사람" }]
  }'

이 경로에는 generationConfig가 없어 화면비·네거티브 프롬프트를 쓰려면 Gemini 네이티브 경로를 쓰거나 프롬프트 문장에 직접 적으세요. messages는 user 한 건만 허용합니다.

응답

{
  "choices": [{
    "message": {
      "role": "assistant",
      "images": [{ "image_url": { "url": "data:video/mp4;base64,AAAAIGZ0eXB…" } }]
    }
  }]
}
POST/v1beta/models/gemini-web-flash-3.8:generateContent일반 대화

요청

curl -X POST "$CLIPROXY/v1beta/models/gemini-web-flash-3.8:generateContent" \
  -H "x-goog-api-key: $CLIPROXY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      { "role": "user", "parts": [{ "text": "한 문장으로 자기소개 해줘" }] }
    ]
  }'

gemini-web-flash 별칭으로도 호출할 수 있습니다. stream: true도 받지만 완성된 응답을 SSE 한 프레임으로 한 번에 보냅니다.

400오류 코드제출 전 거부 · 쿼타 소모 없음
코드의미
omni_unsupported_generation_optiongenerationConfig에 지원하지 않는 키가 있습니다.
omni_invalid_aspect_ratioaspectRatio가 16:9·9:16·1:1이 아닙니다.
omni_invalid_negative_promptnegativePrompt가 문자열이 아닙니다.
omni_single_candidate_onlycandidateCount가 1이 아닙니다.
omni_prompt_length_invalid프롬프트가 비었거나 옵션 문장 포함 8000자를 넘었습니다.
unsupported_omni_request단일 user 텍스트 턴·비스트리밍이라는 형식 조건을 벗어났습니다.
